# 采购全双工复测：轮次打断与检索等待

2026-11-06；会话 `1a9f8d6d-1a30-4143-b41f-32da7966b5f6`。沿用现有 Qwen 全双工及 Viking 链路，未部署缓存、音色或语义轮次优化。本次为单通观察，不是优化后验收。

## 结果

电话接通约 121.25 秒后线路 ended，保存 37 条消息。结束原因为 participant_disconnected；没有定时告别播放事件，不能声称本通验证了主动挂断，也不能仅据此认定由接听人挂断。事件中 report.generated 表明报告生成成功（2392ms）；采样时 session 的 report_status 仍为 generating，属于采集时间先后差异。

16 条助手 turn_timing 中 13 条 interrupted=true。转录中出现“嗯”等短回应及其附近的打断，提示应优先验证附和声处理和语义轮次；尚不能单凭转录排除回声、背景声或用户真实插话。
