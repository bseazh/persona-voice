# Qwen 全双工：口语告别未挂断修复

日期：2026-11-05。Issue #6。修复提交：`e2536b5b83b4e231221f992743fa8195217dcef5`。

## 故障与修正

真实电话第 1 通的自动挂断验收仍记为失败，见 `QWEN_DUPLEX_PHONE_V1_1.md`。最终识别文字“嗯好的好的那就这样拜。”未命中原有完整句结束规则。模型随后回答“好的，再见。”只是普通回复，没有进入结束状态机。

现在补充“那就这样 + 拜/拜拜/再见”的完整口语形式，保留重复应答词处理。结束顺序仍为：拦截新输入与普通回复、终止旧回复、播放一次短结束语、等待播放完成、释放本次电话、释放房间。不能仅凭模型说出“再见”强制挂断。

否定、引用、假设表达及“这样拜师可以吗”不匹配；含糊的“那就这样吧”仍不直接视为结束命令。此修复不调整 VAD 或模型时延参数。
