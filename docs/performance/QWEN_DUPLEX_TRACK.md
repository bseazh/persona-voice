# 独立路线：Qwen 原生全双工实时语音

## 范围

保留 ASR → DeepSeek → TTS 作为默认路线；新增可按会话选择的 `qwen-realtime` 路线。网页与电话使用同一个选择字段，历史会话不改路线。全双工指输入与输出同时传输、支持用户插话；不表示模型不需要判断轮次。

## 必须解决

- 响应与条目 ID 关联，取消后迟到事件不得污染新回答。
- 明确结束意图、后台结束按钮与时长限制进入幂等结束控制，不能依赖模型自愿调用工具。
- 结束语只播放一次；结束语播完才请求释放房间。实际电话释放仍需独立验收。
- 实时双方文字、转录归档、事件日志继续保留；日志注明使用的路线与计时口径。
- 新路线失败不能悄悄切回旧模型并声称成功；原路线可在新建会话时重新选择。

## 验证计划

单元回归覆盖迟到事件、交错响应、明确/否定/引用结束意图与重复结束。真实供应商集成至少两轮，覆盖问答、插话和结束；报告区分接口测试、测试音频 sink、房间输出与实际电话听感。此任务不自动发起真实电话。

前序证据：[Qwen 可行性报告](https://github.com/bseazh/persona-voice/blob/main/docs/performance/QWEN_REALTIME_FEASIBILITY.md)。原先接口两次为 0.769 / 0.872 秒，但自然结束及兼容层未通过；不能把这些数字当成本路线已上线的手机成绩。

## 状态

已作为可选路线部署（`1243803`），旧路线仍默认。两轮严格 AgentSession 集成测试通过；公网真实房间的语音结束和后台结束分别通过。手机 SIM、弱网和长期待机仍待验收，Issue 保持开放。实现与失败/成功测试记录均以评论追加，不覆盖历史。
