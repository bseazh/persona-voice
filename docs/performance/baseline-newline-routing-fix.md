## 证据与原因

第 1 次尝试 `9a143ab9-1d5c-44f8-95a3-4450f965fa92` 中，手机收到新接听号码的 SIP INVITE，但返回 `403 FORBIDDEN`，没有发起蜂窝拨号。读取网关设置确认允许列表仍只有旧的两个号码。

## 修复

2026-11-05 使用已授权的 ADB 配置接口，把新接听号码加入手机允许列表，保留原来的两个完整号码限制，没有放开任意号码。回读确认配置成功、SIM 逻辑槽位仍为 1（SIM 2）、网关 ready、Shizuku CONNECTED、无活动蜂窝通话。

本次只修复拨号前置条件，不计为四项语音优化，不计算响应时延收益。后续第 2 次尝试使用相同语音策略。
